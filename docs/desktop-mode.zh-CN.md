# Windows 星空桌面

在 Windows 版 Alcyone 中打开需要使用的配置，点击顶部的「全部屏幕桌面」。程序会先保存当前配置，再为每个活动显示器创建一个独立的只读画板窗口，放入 Windows 资源管理器的壁纸层。按钮提示中列出屏幕、分辨率和缩放比例。

- 每块屏幕的背景分别铺满动态星空。4000 × 2500 的整个画板在每块屏幕内按比例居中适配，横屏和竖屏各自计算缩放，不跨屏裁切，不显示工具栏、左右设置面板和日志区域。
- 所有屏幕显示同一份配置的星球、航线、星舰和当前运行状态，订阅同一个运行会话。桌面窗口不会读取/写回配置文件、创建额外运行会话或启动自动化任务。
- 桌面模式只展示画板，避免误编辑。Windows 桌面图标和任务栏仍由资源管理器管理。
- 双击系统托盘的 Alcyone 图标，或使用 Ctrl+Alt+F10 打开设置界面，各屏桌面继续显示。若快捷键已被其他应用占用，可使用托盘入口，也可以从任务栏恢复主窗口。
- 设置界面保持原来的缩放和滚动位置。已应用配置的保存和运行变化同步到各屏；切换到另一份配置后，点击「更新全部屏幕」将新的配置应用到所有桌面，并最小化设置窗口。
- 设置界面的「关闭桌面」和托盘菜单的「关闭所有屏幕桌面」只关闭壁纸窗口，不停止状态机。退出程序时清理全部壁纸窗口和托盘，不改写系统壁纸文件，不设置开机自启。
- 使用显示器各自的物理坐标定位，支持主屏左侧/上方的负坐标。监听显示器变化并定期检查 DPI；新增显示器创建画板，断开的显示器移除画板，分辨率/缩放变化重新适配。资源管理器重启后尝试重新挂接各屏窗口；失败则关闭壁纸并显示设置窗口和错误。
- 浏览器托管模式不提供原生桌面挂接。如果资源管理器未提供可用壁纸层，则保留设置窗口并显示错误。

## 编译

```powershell
dotnet build Alcyone/Alcyone.csproj -c Release -o Alcyone/bin/Desktop
```

入口为 `Alcyone/bin/Desktop/Alcyone.exe`。这是常规 .NET Windows 构建，分发时需保留输出目录中的依赖和资源，并安装 .NET 10 / ASP.NET Core 运行时和 WebView2。

本次按要求仅验证编译，不包含 Windows 10/11、资源管理器不同版本及多屏环境的运行验证。壁纸层使用 Windows Shell 非公开的 WorkerW 约定，具体系统兼容性需要实际运行确认。
